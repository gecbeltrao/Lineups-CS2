# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

- `EX_MAPA` / `EXEMPLOS`: textos de exemplo, usados só quando `LINEUPS` não tem nada para aquele mapa e granada. O usuário vai substituí-los pelos lineups reais.
- Sem fotos copiadas da internet: imagens são placeholders tracejados (`.shot` para o lineup, `.banner` para o mapa) até o usuário fornecer `img`.
- Valores de `lado` e `tecnica` precisam bater com as classes `.b.TR`/`.b.CT` e com a lista `TECNICAS`.
